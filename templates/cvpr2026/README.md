# CVPR2026 template

## Overview

This folder contains a LaTeX template for preparing papers in the CVPR 2026 style. The example project and style files are provided to help you compile and adapt your paper quickly.

## Files

- `cvpr.sty` - CVPR style file used by the example document
- `ieeenat_fullname.bst` - bibliography style
- `main.tex` - Example paper entry point
- `preamble.tex` - Shared preamble for `main.tex`
- `rebuttal.tex` - Rebuttal/response template
- `main.bib` - Bibliography database
- `sec/` - Section files used by the example `main.tex`

## Acknowledgement

This template was adopted from the official CVPR 2026 template and adapted for this starter repository.
